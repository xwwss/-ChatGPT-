# Paper Memory MV

30-second 16:9 visual prototype for the song project.

Open `index.html` in a modern browser. The preview is silent and accepts a local LRC file through its import control. Do not commit copyrighted audio or full lyrics to this public repository without the necessary rights.

Current storyboard: old classroom reunion, paper city, stars, flowers, paper boat, memory pages, heart-string, reversed clocks, reunion, and closing book.
