# 复刻回忆 — 30 秒 MV 分镜

## 视觉基调
横屏 16:9。一本立体书放在旧教室课桌上；窗外暖光斜照。采用分层剪纸、水彩纸纹理、柔和投影和轻微纸张弹性。

## 30 秒节奏草案
| 时间 | 画面 |
|---|---|
| 0–4s | 镜头从教室中景缓慢推向课桌，立体书打开，纸艺男女主角出现 |
| 4–8s | 纸烟花逐个绽放，灰色城市楼群弹起，背景墙翻成星空 |
| 8–12s | 许愿星升起，纸艺光束展开，花朵沿书页生长 |
| 12–16s | 纸船漂过层叠波浪，回忆照片连续翻页 |
| 16–20s | 铅笔画褪成灰色，再被橡皮擦回彩色；纸杯电话线上心形移动 |
| 20–24s | 烟花倒放，红线缠绕人物，双层钟面逆向旋转 |
| 24–28s | 空白人物被重新上色，两人靠近并牵手 |
| 28–30s | 书页合拢，红线系成礼物结，镜头停住 |

## 声音设计
