# Project Instructions

You are working on **Pixel Night**, a self-contained pixel-art music-film prototype.

## Before editing
1. Read `docs/PIXEL_STYLE_GUIDE.md`.
2. Inspect the current `index.html` before changing it.
3. Preserve the single-file, dependency-free prototype unless the user explicitly asks to restructure it.

## Technical requirements
- Logical canvas: 320 × 180, 16:9.
- Use Canvas 2D and crisp nearest-neighbor scaling.
- Keep the animation deterministic: rendering a timestamp should produce the same frame.
- Keep playback, pause, resume, restart, and timeline seeking functional.
- Avoid external assets and libraries unless explicitly approved.

## Working style
- Make focused, testable changes.
- Do not claim a feature works unless you have checked the implementation.
- Do not replace the user's existing work wholesale when a smaller edit will do.
- Explain what changed and list any remaining limitations.
- Use original art and audio only; do not copy copyrighted game assets or songs.
